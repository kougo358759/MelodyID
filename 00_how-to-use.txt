鼻歌検索アプリのセットアップおよび実行方法
1. 概要
このプロジェクトは、ユーザーが鼻歌を録音し、その音声データをもとに楽曲を検索できるWebアプリケーションです。録音した鼻歌データをAudD APIに送信し、Spotify APIを使って一致した楽曲の情報や再生リンクを取得して表示します。また、録音中はリアルタイムで音声の波形（オーディオビジュアライザー）を表示します。以下の手順で、セットアップから実行までの流れを解説します。

2. 必要な環境・依存関係のインストール
環境
このアプリケーションは、以下の環境での動作を想定しています。

Node.js および npm（Node Package Manager）
最新のWebブラウザ（Google ChromeやFirefoxなど、Web Audio APIとMedia Recorder APIに対応したもの）
依存関係のインストール
Node.jsを使用して、以下の依存パッケージをインストールします。

bash
コードをコピーする
npm install express
3. プロジェクト構成
プロジェクトファイルは以下の構成になっています。

plaintext
コードをコピーする
project_folder/

4. APIの取得
このプロジェクトでは、AudD APIとSpotify APIを使用します。以下の手順で各APIのトークンやクライアントIDを取得してください。

AudD APIトークンの取得
AudD の公式サイトにアクセスし、アカウントを作成します。
アカウント作成後、ログインして「API Key」を取得します。このキーは、アプリケーションで音楽の特定を行うために必要です。
APIトークンは、index.html内のAPI_TOKENとして設定します。
Spotify APIのクライアントIDおよびクライアントシークレットの取得
Spotify for Developers のページにアクセスし、アカウントを作成またはログインします。
「Dashboard」に移動し、「Create an App」から新しいアプリを作成します。
アプリ作成後、クライアントIDとクライアントシークレットが発行されるので、これらをメモしておきます。
index.html内のSPOTIFY_CLIENT_IDおよびSPOTIFY_CLIENT_SECRETとして設定します。
注意: これらのAPIトークンやシークレットは、他人に漏らさないよう注意してください。安全な場所で管理し、GitHubなどに公開する際は.envファイルなどを使用することをお勧めします。

5. アプリケーションの実装方法
以下は、index.htmlファイルに含まれる主要な機能とその説明です。

録音機能
録音機能は、navigator.mediaDevices.getUserMediaを使用してユーザーのマイクにアクセスし、録音データを取得します。
MediaRecorderを用いて録音を開始し、録音停止時にデータをAudD APIに送信します。
javascript
コードをコピーする
async function startRecording() {
    // ユーザーの許可を求め、マイクをオンにします。
    stream = await navigator.mediaDevices.getUserMedia({ audio: true });
    mediaRecorder = new MediaRecorder(stream);

    // 録音終了時にAudD APIへ音声データを送信
    mediaRecorder.onstop = async () => {
        const audioBlob = new Blob(audioChunks, { type: "audio/wav" });
        await sendAudioToApi(audioBlob);  // 音楽の検索を開始
    };
}
AudD APIによる楽曲検索
録音された音声データは、FormData形式でAudD APIに送信されます。
APIからのレスポンスに基づき、曲名やアーティスト名が表示されます。
javascript
コードをコピーする
async function sendAudioToApi(audioBlob) {
    const formData = new FormData();
    formData.append("file", audioBlob);
    formData.append("api_token", API_TOKEN);

    const response = await fetch("https://api.audd.io/", {
        method: "POST",
        body: formData
    });

    const result = await response.json();
    if (result.status === "success" && result.result) {
        // 結果表示
        document.getElementById("result").innerHTML = `曲名: ${result.result.title} アーティスト: ${result.result.artist}`;
    }
}
Spotify APIによる楽曲情報と再生機能
AudD APIで取得した曲名やアーティスト名をもとに、Spotify APIで詳細情報を取得し、埋め込みプレイヤーを表示します。
javascript
コードをコピーする
async function fetchSpotifyTrack(songTitle, artist) {
    const token = await getSpotifyToken();
    const searchUrl = `https://api.spotify.com/v1/search?q=track:${encodeURIComponent(songTitle)}%20artist:${encodeURIComponent(artist)}&type=track&limit=1`;

    const response = await fetch(searchUrl, {
        headers: { "Authorization": `Bearer ${token}` }
    });

    const searchData = await response.json();
    if (searchData.tracks.items.length > 0) {
        const trackId = searchData.tracks.items[0].id;
        document.getElementById("spotify-player").src = `https://open.spotify.com/embed/track/${trackId}`;
    }
}
オーディオビジュアライザー
Web Audio APIのAnalyserNodeを用いて、リアルタイムで音声波形を表示します。
横長のcanvasエレメントに、取得した音声の周波数データを描画し、視覚的に音の強弱を示します。
6. HTTPSサーバーの起動
このアプリケーションは、マイクのアクセスにHTTPSを使用します。以下のコマンドでHTTPSサーバーを起動し、index.htmlを配信します。

index.js にHTTPSサーバーの設定を記述しています。
javascript
コードをコピーする
const express = require('express');
const https = require('https');
const fs = require('fs');

const app = express();
app.use(express.static(__dirname));

const options = {
    key: fs.readFileSync('./server.key'),
    cert: fs.readFileSync('./server.crt'),
};

https.createServer(options, app).listen(3000, () => {
    console.log('HTTPSサーバーがhttps://localhost:3000で起動しました');
});
以下のコマンドでサーバーを起動します。
bash
コードをコピーする
node index.js
Webブラウザで https://localhost:3000 にアクセスし、アプリケーションが正しく起動することを確認します。
7. 実行手順
Node.jsおよび依存関係をインストール後、APIキーとクライアント情報をindex.htmlに設定します。
HTTPSサーバーを起動し、ブラウザでアプリにアクセスします。
「録音開始」ボタンをクリックし、鼻歌を録音します。
録音停止後、楽曲情報が表示され、Spotifyプレイヤーで再生できるようになります。
8. 注意事項
APIリクエストの制限: AudD APIとSpotify APIには利用制限があり、無料プランでは一定の回数を超えると制限がかかります。
ブラウザの設定: 最新のWebブラウザを推奨します。HTTPSでのマイクアクセスが必要なため、ローカル環境でもHTTPSが求められます。
APIキーの管理: APIキーやシークレット情報は、.envファイルで管理し、公開リポジトリに含めないように注意してください。
